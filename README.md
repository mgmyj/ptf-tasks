# מערכת ניהול משימות – פריסה

`server.js` הוא קובץ שרת מאוחד (נבנה מקוד המקור) הכולל את כל התלויות ואת ממשק האתר.

- הפעלה: `npm start` (Node.js 22.13+)
- משתני סביבה חובה: `APP_URL`, `JWT_SECRET`
- לשמירת נתונים בשרת שהדיסק שלו נמחק: `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`
- כל שאר ההגדרות (מייל, מפתחות API) מוזנות מתוך האתר.
